
### 1.5.22 v10：最终配置的全套 8 场景成绩（Demo A 正式数字）

配置（`run_final8.sh rt8_v10 20 support`）：

    Grounding DINO-Base + SAM2.1-hiera-base-plus
    提示词 48 个，分 2 组（大件/软装 22 + 小件/灯具/电子 26）
    每个检测帧两组都查，跨组 NMS（IoU 0.60）去重
    检测间隔 20，中间帧纯几何传播（stride 2，最小面积 150 px）
    标签别名归一 + 跟踪器 support 档门控
    2000 帧/场景，kNN 5 cm，COCO 101 点插值

新的 headroom 已经被打开——agnostic/seen 仍有 71.8，labeled/seen 66.4，
中间 5.4 分是被标签拖掉的（v6 是 15.7 分，已经收窄了三分之二）。

**剩下的缺口在哪（按已量化的大小排序）**

1. **实例质量**（AP50/75 的主要来源）。排序用 oracle 可达 45.3 / 23.5 / 10.9
   （1.5.20），比现在的 42.6 / 14.7 / 5.1 高 +2.7 / +8.8 / +5.8。需要一个
   "实例质量"打分器，用留一场景交叉验证训练，不能用 Replica 直接刷分。
2. **小物体召回**。lamp / book / box / bottle / tablet 这几类平均 IoU 仍在
   个位数（1.5.18）。support 门控已经在 room_0 上证明有效（28.2 → 41.4），
   但检测器本身给框的次数还是太少（office_2 的 box 2000 帧只出现 40 次）。
3. **AP25 到 AP50 的落差**。62.6% 的顶点覆盖对应 AP25 42.6，但 AP50 只有 14.7
   ——大量实例是"覆盖了但没抠准"，典型是过分割（一把椅子裂成坐垫+靠背）。
